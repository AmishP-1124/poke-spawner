# poke-spawner

A PokéTwo-style Pokémon spawner website — spawns Pokémon randomly for catch/trade gameplay, with a secret admin command to spawn any Pokémon with perfect stats.

## Setup

1. Clone the repo: `git clone https://github.com/AmishP-1124/poke-spawner.git`
2. Open `index.html` in your browser
3. Start playing!

## Features

- Random Pokémon spawns
- Secret admin command for perfect stats
- Catch & trade mechanics
- Discord notifications for new Pokémon drops
